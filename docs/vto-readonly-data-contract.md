# Данные VTO для ускорения синхронизации

Прямой доступ сейчас не предоставлен. Для переговоров предпочтителен официальный
read-only API или периодический CSV/JSON-экспорт; альтернатива — ограниченные
SQL views на реплике, без доступа к основной базе магазина.

Нужны отдельные сущности:

- Семейство: стабильный product ID, название, описание, бренд, категории, URL.
- Вариант: реальный variant ID, parent ID, SKU, цвет, размер, материал, свои фото.
- Цена: variant ID, точная сумма, валюта и время изменения.
- Остаток: variant ID, склад, свободное/зарезервированное/ожидаемое количество,
  дата поступления, время наблюдения и признак общего остатка родителя.
- Изменения: `updated_at` или последовательный cursor, удаления/архивирование,
  пагинация, контрольный полный список ID и согласованный snapshot timestamp.

Отсутствующее количество должно передаваться как NULL, известный ноль — как 0.
Родительский общий остаток нельзя дублировать по вариантам. Нужны документированные
лимиты, правила повторов, часовой пояс, SLA и контакт для изменений схемы.

Доступ: только SELECT на согласованные views либо scoped API token; TLS,
ограничение IP/VPN, без таблиц покупателей, заказов, паролей и платёжных данных.
Секреты передаются отдельно от Git. Импорт сохраняет локальный PostgreSQL-индекс;
пользовательский поиск не должен зависеть от доступности базы поставщика.
